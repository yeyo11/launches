Running several Claude Code agents on one Linux box? Sluice is a shared verification queue and cache: each gate (tests, linters, type checks) runs once per git tree, under one CPU and memory budget.

Open source, MIT, written in Rust. About 28 hours of checks skipped in a week on my two machines.

https://josegarrido.dev/en/sluice-shared-queue-so-your-agents-stop-repeating-tests/?ref=mastodon

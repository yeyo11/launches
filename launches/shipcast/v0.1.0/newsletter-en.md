Subject: Shipcast v0.1.0: one release, every channel
Preview: A tool that reads your repo's code and writes the launch for each channel, published once you approve it.

Hi,

This week I published the first version of Shipcast, the tool I built so I would stop rewriting the same announcement every time I ship a release.

You publish a release and Shipcast reads the project's code, not just its README. It then writes the article in English and Spanish and a piece for each channel, and opens a pull request with the drafts. When you merge it, each channel is published once: blog, dev.to, Bluesky, Mastodon, Instagram and the newsletter. Show HN and Product Hunt come as drafts for you to post.

I already used it to launch claudio v0.9.0, and this very issue is part of Shipcast's own launch.

The article walks through `launch.yml`, the pre-flight check, the commands and the web app:

[Read the article](https://josegarrido.dev/en/shipcast-launch-your-github-projects/?ref=newsletter)

The code is at [github.com/yeyo11/shipcast](https://github.com/yeyo11/shipcast). If you try it, reply and tell me how it went.

Subject: Shipcast v0.1.0: una release, todos los canales
Preview: Una herramienta que lee el código de tu repo y escribe el lanzamiento de cada canal, publicado cuando tú lo apruebas.

Hola,

Esta semana he publicado la primera versión de Shipcast, la herramienta que hice para dejar de reescribir el mismo anuncio cada vez que saco una release.

Publicas una release y Shipcast lee el código del proyecto, no solo el README. Después escribe el artículo en inglés y en español y una pieza para cada canal, y abre un pull request con los borradores. Cuando haces merge, cada canal se publica una sola vez: blog, dev.to, Bluesky, Mastodon, Instagram y la newsletter. Show HN y Product Hunt llegan como borradores para que los publiques tú.

Ya lo usé para lanzar claudio v0.9.0, y este mismo número forma parte del lanzamiento de Shipcast.

En el artículo explico `launch.yml`, el pre-flight, los comandos y la app web:

[Lee el artículo](https://josegarrido.dev/es/shipcast-lanza-tus-proyectos-de-github/?ref=newsletter)

El código está en [github.com/yeyo11/shipcast](https://github.com/yeyo11/shipcast). Si lo pruebas, respóndeme y cuéntame qué tal.

José Antonio

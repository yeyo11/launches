I built Claudio: it runs Claude Code as a service. The CLI sits behind a REST API and a web UI, so you can start and answer chats from a browser or phone, run agents in parallel git worktrees, and move work to another Claude account before a limit. It only uses the CLI's own interface. Self-hosted, MIT, v0.9.0. https://josegarrido.dev/en/claudio-run-claude-code-as-a-service/?ref=mastodon #ClaudeCode #SelfHosted #OpenSource #AIAgents

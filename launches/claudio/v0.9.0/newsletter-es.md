Subject: Claudio 0.9.0: Claude Code como servicio
Preview: Una API REST y una web sobre la CLI de Claude Code, con agentes en paralelo y rotación de cuentas.

Hola,

Llevo mucho tiempo usando Claude Code desde la terminal y siempre echaba de menos poder iniciar una conversación desde el móvil, ver qué agente estaba esperándome y seguir trabajando cuando una cuenta se quedaba sin cuota. Claudio es lo que construí para eso, y la v0.9.0 es la primera vez que lo presento como se merece.

Pone la CLI de Claude Code detrás de una API REST y una interfaz web. Ejecuta agentes en paralelo, cada uno en su propio worktree de git, te enseña el diff de lo que cambió y pasa el trabajo a otra cuenta de Claude antes de llegar a un límite. Solo usa la interfaz que la CLI ofrece a los programas, así que llega hasta donde llega la CLI y no más.

El artículo trae los comandos de instalación para Docker, la app de escritorio para Linux y el código fuente.

[Lee el artículo](https://josegarrido.dev/es/claudio-claude-code-como-servicio/?ref=newsletter)

Si lo pruebas y algo falla, responde a este correo o abre una issue.
